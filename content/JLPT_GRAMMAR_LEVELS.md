# JLPT 等級文法對照表

用途：「文章解析」功能生成文法點時查表用——**同一個文法點只在它第一次出現的等級解說，更高等級遇到就跳過**（例如「も」在 N5 就解說過，N4 以上文章再出現不重複解說）。

等級對應：`n5_lite`／`n5` → 查 N5 區；`n4_lite`／`n4` → 查 N4 區；以此類推。lite 版跟正式版共用同一套文法範圍，差別只在句子長度/詞彙難度，不是文法難度。

**規則：查表時由上而下找——文法點若已出現在較低等級（N5 → N4 → N3 → N2 → N1），高等級文章遇到就跳過，不重複解說。只有「這個等級新出現」的文法點才需要解說。**

---

## N5（基礎）

| 文法點 | 說明 |
|---|---|
| 〜は〜です／〜ではありません | 「是」的肯定/否定敘述句 |
| 〜が（主語標記） | 標示句子的主語（與は的差異：新資訊/焦點 vs 主題） |
| 〜を（受詞標記） | 標示動作的對象 |
| 〜に（時間/對象/到達點） | 表示時間點、動作對象、或到達的地點 |
| 〜で（場所/方法） | 表示動作發生的場所，或使用的方法/工具 |
| 〜へ（方向） | 表示移動的方向（口語常與に互換） |
| 〜と（並列/一起） | 連接名詞表示「和」，或表示「跟誰一起」 |
| 〜も（也） | 「也」，會取代が/を，但と、で等助詞保留 |
| 〜の（所屬/修飾） | 表示所屬關係，或名詞修飾名詞 |
| 〜から〜まで | 「從〜到〜」，時間或地點的範圍 |
| 動詞ます形 | 禮貌體現在式，肯定/否定/過去/過去否定四段變化 |
| 動詞て形 | 連接兩個動作（先後順序）、或用於て形句型（ている等） |
| 〜ている（進行/狀態） | 表示動作正在進行，或動作結果的持續狀態 |
| い形容詞（現在/否定/過去/過去否定） | い形容詞的四段變化：〜い／〜くない／〜かった／〜くなかった |
| な形容詞（現在/否定/過去/過去否定） | な形容詞加です的四段變化 |
| 〜くて／〜で（形容詞て形） | 連接兩個形容詞子句，表示並列或原因 |
| 〜たい（想要） | 動詞ます形去ます加たい，表示說話者的願望 |
| 〜ながら（一邊〜一邊） | 表示兩個動作同時進行 |
| 〜たり〜たりする | 列舉動作，「或做〜或做〜」 |
| 〜ことができる（可能） | 表示能力或可能性 |
| 〜前に／〜後で | 「〜之前」／「〜之後」，表示時間先後 |
| 疑問詞（誰/何/どこ/いつ/どう/どのぐらい） | 基礎疑問句構造 |
| 〜ましょう／〜ませんか | 提議、邀約句型 |
| 〜てください | 請求、指示 |

## N4（初中級，僅列 N5 未涵蓋的新文法）

| 文法點 | 說明 |
|---|---|
| 普通形（辞書形/ない形/た形/なかった形） | 常體，用於複句、思考/傳聞句型前接 |
| 〜と思う | 「我覺得〜」，表示個人想法 |
| 〜という | 「叫做〜」，用於引用名稱或說法 |
| 〜たら（條件） | 「如果〜的話」，一次性條件或發現用法 |
| 〜ば（條件） | 假設條件，較書面/文法性的「如果」 |
| 〜なら（條件） | 針對對方所說的話題提出建議或條件 |
| 〜そうだ（傳聞/樣態） | 「聽說」或「看起來」，依接續判斷語意 |
| 〜らしい（推測） | 根據客觀依據的推測，「好像」 |
| 〜ようだ／〜みたい | 主觀推測或比喻，「好像」 |
| 〜のに（雖然/卻） | 逆接，帶有不滿/意外語氣 |
| 〜ので（因為） | 客觀原因，比から更委婉/書面 |
| 受身形（〜れる／〜られる） | 被動語態 |
| 使役形（〜せる／〜させる） | 使役語態，「讓〜做」 |
| 使役受身形 | 「被迫做〜」 |
| 〜てもいい／〜てはいけない | 許可／禁止 |
| 〜なければならない／〜なくてもいい | 義務／不需要 |
| 〜ておく | 事先準備、放著不管 |
| 〜てしまう | 動作完成（遺憾/徹底語氣） |
| 〜てみる | 嘗試做某事 |
| 〜てあげる／〜てくれる／〜てもらう | 授受表現（幫忙的方向性） |
| 〜すぎる | 「太〜」，程度過度 |
| 〜やすい／〜にくい | 「容易/難以〜」 |
| 〜てから | 「做完〜之後」，強調先後 |
| 〜つもりだ | 打算、預定 |
| 〜予定だ | 預計、行程安排 |

## 使用方式（給生成 prompt 用）

1. 依文章等級找到對應區塊。
2. 從文章句子中挑出**符合這個等級新範圍**的文法點（不超過 4 點，挑教學價值最高的，不必每句都找）。
3. 若一個文法點在較低等級已經出現過（例如ている在N5），高等級文章即使用到，也**不需要再解說**——只挑「這個等級才第一次教」的點。
4. 找不到符合本等級新範圍的文法點時（例如文章全用基礎文法），該篇「文章解析」可以留空或只放 1 點，不必硬湊。
